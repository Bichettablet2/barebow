# Barebow Tracker Pro

Aplicación web para seguimiento de entrenamiento de arco desnudo (barebow).

## 🎯 Características

- **Dos modalidades**: Sala (18m, diana 40cm) y Exterior (50m, diana 122cm)
- **Registro de flechas**: Toca la diana para registrar cada tiro
- **Análisis por posición**: Identifica tus mejores y peores flechas
- **Estadísticas completas**: Media, récord personal, distribución por zonas
- **Temporizador**: Entre series con botón flotante
- **Exportar datos**: CSV para compartir con entrenador
- **Offline**: Funciona sin conexión una vez cargada

## 📱 Instalación en iPhone

1. Abre la URL en **Safari**
2. Toca el botón **Compartir**
3. Selecciona **Añadir a pantalla de inicio**
4. ¡Listo! Aparecerá como una app nativa

## 🛠️ Tecnologías

- HTML5 + CSS3 + JavaScript puro
- LocalStorage para guardar datos
- Sin dependencias externas
